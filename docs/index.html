The Core Narrative: M5 Hardware Jump vs. M4 Software Jump

Apple's latest silicon (M5) achieves generational leaps in language model prefill (Time-To-First-Token) via hardware-level memory bandwidth scaling, larger System-Level Caches, and dedicated matrix coprocessor blocks.

"While Apple achieves these gains through new silicon fabrication, this project demonstrates that a similar magnitude of improvement for the prefill-specific bottleneck can be achieved on current-generation hardware (Apple M4) through deep, low-level software engineering."

Through 128-bit LSU queue saturation, dynamic Q8_0 FlashAttention, and dual-tier double buffering, this engine demonstrates a verified ~3.4x to 3.7x True GPU Speedup for full-layer prefill on the existing Apple M4 MacBook Air.

The 5 Core Physical Innovations

  1. Fused 4-in-1 ALU Dequantization: Bit-masking and single-cycle FMA math unpacking 4 weights in 2 instructions.
  2. Memory Queue Saturation via 128-bit Vector Reads: Saturated the M4 LSU in-flight load queue to its optimal ~2.0 KB depth (+43% bandwidth throughput).
  3. Dual-Tier Double Buffering: Staged activation tiles and register weight pockets to hide memory latency behind compute.
  4. Fused FlashAttention with Dynamic Q8_0 KV Cache: Online softmax in registers with causal block skipping (saving 49.2% FLOPs) and 46.9% memory reduction.
  5. Fused SwiGLU & Direct-Head Projection: Direct-head output layout bypassing transpose passes; in-kernel SiLU * Up saves 23 MB DRAM traffic per layer.
